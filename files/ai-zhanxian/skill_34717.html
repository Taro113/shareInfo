简介

前端样式还原助手，帮助 AI 根据设计稿和切图准确还原 UI 样式代码。核心能力：自动处理 750px 设计稿 → CSS 的尺寸换算，无需用户每次重复说明尺寸规范。

触发条件：用户提到"还原设计稿"、"按设计稿写样式"、"这是切图帮我写 CSS/SCSS"、"帮我实现这个组件"，或上传了设计截图/切图并要求编写前端样式时触发。

规则优先级

本 skill 的所有默认规则在用户没有特殊说明时自动生效。如果用户在对话中给出了明确的指令或特殊要求，以用户指令为准，覆盖对应的默认规则。

尺寸换算规则（必须严格遵守）

设计稿画布：750px 宽（@2x），切图导出倍率：1.5x，编码目标视口：375px（@1x）

来源换算方式示例
设计稿标注值 → CSS÷ 2标注 96px → CSS 48px
切图尺寸 → CSS÷ 3切图 144px → CSS 48px
切图尺寸 → 设计稿标注值÷ 1.5切图 500px → 标注 333px

禁止行为：

  • 不得把设计稿标注值直接当 CSS 值使用（如标注 96px 直接写 height: 96px）
  • 不得把切图尺寸直接当 CSS 值使用
  • 不得把切图尺寸 ÷ 2（切图是 1.5x 不是 2x）

切图默认约定

用户上传的图片文件，默认视为 750px 设计稿的 1.5x 切图，直接按切图尺寸 ÷ 3 换算 CSS 值。

有切图时必须直接使用切图，禁止用 CSS 重新绘制。只有纯色块、文字、简单几何（如纯色圆角矩形按钮）才允许纯 CSS 实现。

// 背景图
.banner {
  width: 375px;          // 切图宽 1125px ÷ 3
  height: 200px;         // 切图高 600px ÷ 3
  background-image: url('./banner.png');
  background-size: 100% 100%;
  background-repeat: no-repeat;
}

工作流程

  • 识别输入类型：切图文件、设计稿截图，还是文字描述的尺寸标注
  • 判断是否有切图：有切图 → 直接引用，不用 CSS 重绘
  • 应用换算规则：根据上方公式换算所有尺寸，不询问用户换算方式
  • 识别技术栈：优先沿用项目已有技术栈（SCSS/CSS/Less），无法判断时默认输出 SCSS
  • 输出样式代码：按项目规范输出

输出规范

尺寸单位：布局尺寸（width/height/padding/margin/gap）使用 px；字号使用 px；圆角使用 px；行高优先使用无单位倍数（如 1.4）。

SCSS 输出格式：使用 BEM 命名（.block__element--modifier）；嵌套层级不超过 3 层；颜色值直接写十六进制，不造假变量名。

与用户沟通时的尺寸表达

在回复中提到尺寸时，统一使用 750px 设计稿的标注值（如"按钮高度 96px"），代码中写 CSS 换算值（48px），两套数字各司其职，不要混用。

遇到不确定的情况：有标注值 → 优先用标注值 ÷ 2；只有切图没有标注 → 用切图尺寸 ÷ 3；两者都没有 → 根据视觉比例估算，并在代码注释中说明是估算值。
