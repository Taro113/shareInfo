简介

酒旅营销活动 SDD 流程设计规范。移动端设计规范参考，包含颜色、字体、间距、圆角、阴影、组件等规范，帮助 AI 生成符合设计规范的前端样式代码。

当用户需要编写前端样式、实现 UI 组件、还原设计稿，或询问颜色/字号/间距/圆角/按钮/弹窗等设计规范时触发。

全局前提

尺寸换算（必读）

所有规范数值均基于 750px 移动端设计稿（@2x），编码时视口为 375px（@1x），所有数值除以 2 转为 CSS 值。

设计稿值CSS 值
24px 边距12px
28号字font-size: 14px
96px 按钮高度height: 48px
36px 圆角border-radius: 18px

对比度原则（强制）

  • 浅色背景用深色文字（#111111 / #555555 / #888888）
  • 深色背景用白色文字
  • 黄色背景（#FFDD00）必须用深色文字（#7A3100 或 #111111），禁止白色文字
  • 置灰色 #C2C2C2 仅用于禁用状态，不可用于正常可读内容
  • 禁止低对比度组合（浅黄背景+白字、浅灰背景+置灰文字等）

颜色使用原则

  • 所有颜色平级，根据项目画面风格自行选定一套主色和辅助色
  • 同一项目内同类型元素（主按钮、背景色、强调色）必须使用同一颜色
  • 从色库中选取 1~2 个主色、1 个辅助色即可，保持画面整体协调
  • 禁止出现同一页面内按钮五颜六色、背景色杂乱的情况
